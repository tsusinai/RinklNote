## 一、聚焦解决：流程麻烦的记账问题

通过**侧边快捷栏**和 **AI 按键**实现"复杂度低、效率要求高"的记账要求，满足保存**"及时性记忆"**的需要——想到就记，不超过一句话的成本。

| 传统路径 | 操作步数 |
|---|---|
| 打开 App → 找到记账页 → 输金额 → 选分类 → 选账户 → 点确认 | ≥ 6 步 |
| 忘了记 → 事后补记要回忆金额/时间/分类 | 更高 + 更痛苦 |

## 五、构建效果

### 5.1 改进部分

**简化入账流程**：使用 AI/NLP 自动解析处理，降低用户记账流程复杂度，实现"**助理式**"记账体验——一句话落账 ✅。
- NLP 解析：`POST /api/bills/parse`（规则 + LLM 双通道），离线本地 `VoiceParser` 兜底。
- 一步落账：去两段确认门禁（`bcc8e20`/`8b445ce`），语音 / 对话确认直接保存。

**侧边抽屉式 UI**：为传统记账流程提供新的选择，提升记账舒适度与效率 ✅（`009203c` 抽屉二级分类交互：长按弹层跟随母标签、选中不收回、展开动画）。

### 5.2 查账流程优化

**AI 页智能判断"记账"还是"问账"** ✅（`AiViewModel` `46d848a`）：支持**账单总结**（月度总结 / 异常提醒）与**账单问题总结**（自然语言查账）。

## 六、AI 脱敏与隐私（答辩追问）

记账数据是最私密的个人数据，而 NLU / 总结都经过 LLM。**"AI 到底见到什么"是答辩最可能被追问的点**。

| 能力 | LLM 拿到什么 | 现状 |
|---|---|---|
| 记账解析 | 仅那句文本 + 分类表 | ✅ 最少必要 |
| 月度总结 | 仅聚合：月总额 + TOP5 | ✅ 无明细无备注 |
| 异常检测 | 纯本地计算，不调 LLM | ✅ 零外传 |
| 自然问账 | 问句 + 最近 10 笔明细（含备注） | ⚠️ 泄露点 |

原则：**最小化、聚合化、匿名化（不送身份）、不落盘、可关闭**。独立/继续迭代时把问账的备注剥离即可闭合（`InsightService.naturalQuery`）。
