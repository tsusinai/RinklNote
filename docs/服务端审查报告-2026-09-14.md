# RinklNote 服务端全面审查报告（2026-09-14）

> 审查方式：三域只读扫描（安全/路由、服务与数据层、基础设施与测试）+ Critical 项人工复核。证据格式 `文件:行号`，行号为审查时快照。基线：main `8d2b1a2` 复核确认全部 Critical 仍存在。
> 处置：本报告随修复分支 `fix/server-audit` 落档，每项修复独立提交并在提交信息回链本节编号。

## Critical

- **C1 · PostgreSQL 启动即崩**：`plugins/Database.kt` 迁移链中 `SELECT ... FROM INFORMATION_SCHEMA.INDEXES`（H2 私有视图，PG 无）无 try/catch；`ALTER COLUMN phone SET NULL` 非 PG 语法，PG 中语句失败中止整个事务并级联。异常逃出 `runMigrations` → `configureDatabase` 无兜底 → 服务器无法启动且建表一并回滚。
- **C2 · QQ op=13 签名预言机**：`routes/QQBotWebhookRoutes.kt` op=13 对任意 `(eventTs, plainToken)` 无认证返回 Ed25519 合法签名（与 op=0 验签同钥），可签出任意消息绕过 webhook 验签。
- **C3 · 全局 Bot 配置任意用户可写**：`routes/QQBotManageRoutes.kt` `POST /api/qq-bot/config` 仅 JWT、无管理员角色，开放注册下任何人可接管 Bot；clientSecret 明文落 `bot_config`（技术文档声称 BCrypt 加密，与实现相反）。

## High

- **H1 · 注册限流失效**：`routes/AuthRoutes.kt` 注册 `recordFailure` 仅在「手机号已注册」分支调用，成功注册不限量 → 批量开户（直接喂给 C3）。
- **H2 · 隐私 NFR 字面违约两处**：`services/nlu/LearningService.kt` 将用户 `originalText` 原文拼进 LLM prompt（裁定：属用户当次主动输入，与 NLU 实时解析同类，保留）；`services/insight/InsightService.kt` `naturalQueryContext` 含「最近10笔」逐笔明细行，违反「绝不送未聚合明细」硬约定（裁定：修复，改聚合）。
- **H3 · 测试盲区**：`Money.resolveAmountMinor`、BillRoutes 条件 PUT 409 语义、QQBot Ed25519 验签 0 覆盖；13 个路由文件零 HTTP 层测试（缺 ktor-server-test-host 依赖）。

## Medium（摘要）

BillRoutes PUT 不校验 accountId 归属；GET /api/budgets 泄漏软删除行 + upsert 读-判-写竞态 + amountMinor 无 >0 校验；QQ 消息 at-most-once 丢失链（判重先于处理 + 开户/关键词竞态被 catch-all 吞）；WS 干净关闭零退避热重连 + 无 RESUME；JWT issuer/audience env 读取不对称（签发读 env、校验不读 → 配 env 即全线 401）；bind-qq 无所有权证明；suggest-config 全局可写；ExposedSQLException 包装致 StatusPages 约束冲突分支疑似死代码【需实测】。

性能：habit 推送无时段闸门（每用户每 30s 全历史扫描）+ 推送失败 LLM 每 30s 重打；`allBills` 全量扫描遍布 insight 端点；bills 增量拉取依赖墙钟（回拨漏单）；`InMemoryRateLimiter.prune()` 无调用点。

## Low（摘要）

手机号/qqNumber 无长度校验（超长落 500）；sync limit 可整数溢出；Bot 配置保存失败回显原始异常；绑定码/签名明文进 INFO 日志；LLMParser 用 printStackTrace；PG 默认凭据 rinklnote/rinklnote 双重硬编码；anomalyCheck 分母硬编码 30 天；文档过期十余处（README「QQ 改密 null 崩溃」债务实际已修复，可销）。

## 已查无发现（正面确认）

认证覆盖完整；常规 CRUD 无 IDOR；验签恒时安全；JWT secret 有 fail-fast；金额整数分全链路一致（旧浮点列只写不读且同源）；bills 同步游标协议正确；Insight 报表端点月份边界/时区/LLM 降级正确；改密对 null hash 已安全；ASR 无句柄泄漏；NLU 无状态污染。
