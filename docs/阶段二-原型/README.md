# 阶段二 · 核心页面原型（真机截图）

> 本目录存放 RinklNote 真机截图，作为阶段二「改进方案 → 原型」交付物的一部分。
> 每张图配一句交互说明，共 6 张关键页。截图由开发者在真机（Redmi · HyperOS）上手动截取。

## 截图清单与命名约定

请按下表命名并放入本目录（文件名即插图顺序）：

| # | 文件名 | 页面 | 交互说明（一句） |
|---|--------|------|------------------|
| 1 | `01-记账页.png` | 记账首页（计划/记账/资产 三 tab 中间页） | 顶部三图标：更多→我的 / 金融→资产 / 登记→记账抽屉；中部图表 + 月账单列表；右下 FAB 呼出快捷记账抽屉 |
| 2 | `02-计划页.png` | 计划页 | 本月预算卡片，可点击「设置」进入预算编辑 |
| 3 | `03-资产页.png` | 资产页 | 账户余额列表，点击可编辑余额 |
| 4 | `04-快捷记账抽屉.png` | 快捷记账抽屉（右侧滑出） | 智能推荐 / 快捷模板 / 标签栏（长按呼出二级分类动画）/ 账户选择 / 底部 AI 语音按钮 / 金额框 |
| 5 | `05-AI页.png` | AI 记账 + 综合助手（聊天式） | 语音 / 文本输入条：说「午餐 28 元」→ 聊天内确认记账；「这个月花了多少」→ 问账回答 |
| 6 | `06-我的页.png` | 我的页（全屏覆盖层） | 导出 CSV、修改密码、QQ 机器人绑定入口 |
