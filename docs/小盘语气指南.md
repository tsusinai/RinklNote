# 小盘语气指南（2026-09-18 · Task 1.5）

> 「小盘」是 RinklNote 的记账吉祥物人格，四通道 Bot 推送（QQ / 飞书 / 企微 / 订阅号）、
> 服务端告警、周报与回执文案统一按本指南输出。实现层入口：`server/.../services/coach/MascotVoice.kt`。

## 1. 身份与称呼

- 自称**小盘**（不是「我」「本机器人」）；偶尔用「小盘帮你盯着呢」。
- 称呼用户一律**「你」**，不叠词（不叫「亲」「您呐」「宝子」）。
- 定位一句话：*小盘是你的记账小帮手*——只帮忙记账、看账、提醒，不替用户做决定。

## 2. 口吻

- 像熟悉的朋友，**温和、轻松、简短**；语气词用「～」「啦」「呀」「好嘞」，一条最多一个。
- emoji 是标点不是装饰：单条推送 **≤3 个**，只从 `✅ 📊 ⚠️ 🔍 🔥 👍 🧾 🚨` 里选。
- 金额一律 `¥` + 两位小数（走各端 Money 工具，不手写小数）。
- 报数字先给结论再给细节：「已记录：三餐 ¥20.00」而不是「你的午餐消费记录为…」。

## 3. 禁止项

1. **不说教、不评判消费**：不说「你应该」「你必须」「又乱花钱」「再这样下去…」。
2. **不堆感叹号**：连续 `!!`/`！！` 一律出现即违规；一条里感叹号 ≤1 个（能不用就不用）。
3. **不阴阳怪气、不装可怜、不卖惨求关注**。
4. **不泄露明细**：推送里绝不出现备注原文、单笔明细；只引用聚合数字与分类名（隐私红线）。
5. **不承诺做不到的事**：不说「我帮你省下」这类保证，只给观察和建议。

## 4. 固定文案锚点（实现与测试共同锁定）

| 场景 | 锚点（必须包含） | 示例 |
|---|---|---|
| 记账回执 | 「已记录」 | 已记录：三餐 ¥20.00，小盘帮你盯着呢～ |
| 删除回执 | 「已删除」 | 已删除：三餐 ¥20.00（9/18） |
| 撤销最近一单 | 「已撤销最近一单」 | 已撤销最近一单：三餐 ¥20.00（9/18） |
| 日报标题 | 「✅ {date} 账单总结」 | ✅ 2026-09-17 账单总结 |
| 周报标题 | 「🧾 小盘周报」 | 🧾 小盘周报 |
| 异常告警标题 | 「🚨 小盘异常汇报」 | 🚨 小盘异常汇报 |

## 5. 改文案的流程

1. 先改本指南，再改 `MascotVoice.kt`（文案函数一律带单测：非空、锚点、无连续感叹号）。
2. 新场景文案先在 `MascotVoice` 落函数再接线，**不允许**在处理器/路由里裸写字符串。
3. 贺图 / 形象资源只用 `resource/二次元logo/` 现有资产，不新画。
