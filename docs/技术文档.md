## 同步协议

### 双向同步 (Last-Writer-Wins)

**推送（Android → 服务器）：**
```
1. 查本地 server_id == null 的账单
2. POST /api/bills → 获得服务端 ID
3. 更新本地 server_id = 返回值
```

**拉取（服务器 → Android）：**
```
1. GET /api/bills/sync?after=<lastSyncTime>&limit=200
2. deleted=true → 本地删除
3. deleted=false → 按 server_id upsert
4. updatedAt 大的胜出 (Last-Writer-Wins)
5. 更新 lastSyncTime = response.serverTime
```

**冲突处理：**
- 每条账单有 `updatedAt` 字段
- 写入时服务端校验 `updatedAt` > 当前值
- 拉取时比较 `local.updatedAt` vs `server.updatedAt`，保留较新的

## NLU 解析管线

```
输入文本
  ↓
1. 正则提取金额 (优先元/块后缀, fallback 最后数字)
  ↓
2. 用户关键词匹配 (DB, 按优先级 DESC)
  ↓  命中 → 返回分类
  ↓  未命中 ↓
3. 系统关键词匹配 (RuleBased: 餐→三餐, 打车→交通...)
  ↓  命中 → 返回分类
  ↓  未命中 ↓
4. LLM 解析 (DeepSeek API)
  ↓  成功 → 自动保存关键词 (priority=5) → 返回分类
  ↓  失败 ↓
5. 返回金额(无分类)
```

## 智能推荐算法

```
输入: userId, 当前时间
1. 读取 suggest_config (Web 配置)
2. 确定当前时段窗口 (早餐 7-10 / 午餐 11-14 / 晚餐 17-20)
3. 查最近 N 天账单 (配置: lookbackDays, 默认7)
4. 按 (categoryName, amount) 分组, 取出现次数最多的
5. 次数 >= minOccurrences (默认3) → 返回推荐
6. 否则返回空
```

## QQ Bot 接入

### Webhook 验证流程
```
QQ 发送 op=13 → 提取 plain_token + event_ts
→ Ed25519 签名 (event_ts + plain_token)
→ 返回 {plain_token, signature}
```

### 消息处理流程
```
QQ 发送 op=0 → 验证 X-Signature-Ed25519 (强制)
→ 返回 {op:12} ACK
→ 异步处理:
  → 提取 content, user_openid, msg_id
  → 查 userService.findByQqOpenid(openid)
  → 未绑定 → 生成6位绑定码 → 回复
  → 已绑定 → NLU 解析 → 创建账单 → 回复结果
```

### 安全措施
- Ed25519 签名强制验证（不可绕过）
- AppSecret 加密存储（BCrypt via BouncyCastle）
- JWT 认证 (HMAC256, 24h 过期)
- 绑定码 5 分钟过期

## 部署

### 服务端
```bash
./gradlew :server:installDist
tar -czf rinklnote-server.tar.gz -C server/build/install server/
scp rinklnote-server.tar.gz jmbot:/tmp/
ssh jmbot "systemctl stop rinklnote && tar -xzf /tmp/rinklnote-server.tar.gz -C /home/admin && systemctl start rinklnote"
```

### Web
```bash
scp web/index.html jmbot:/tmp/web-index.html
ssh jmbot "cp /tmp/web-index.html /var/www/rinklnote/index.html"
```

JWT_SECRET=<secret>
