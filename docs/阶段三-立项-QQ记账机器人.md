# 阶段三 · 一句话立项 + 评审预演 —— QQ 记账机器人

> 课程：AI 产品开发 · 阶段三（Week 6：一句话立项 + 立项评审）
> 定位：**个人记账坚持路线**（个人坚持 → 习惯闭环；群共享/AA 留作 v2 扩展 wedge）
> 本文件是立项答辩前的完整弹药库：一句话 → 叙事 → 技术底牌 → challenge 预演 → 自检。

---

## 一句话立项

> 在 QQ 里说一句「午餐28元」就记好账，月底自动收到消费总结和异常提醒——
> 把记账从「打开 App 点 5 下」降到「说一句话」，靠**主动推送**帮你把记账坚持下来。

（备选一句，更强调痛点：）做一个 QQ 记账机器人，给「装过记账 App、却因为麻烦而坚持不下来」的人用。

---

## 核心叙事：是「摩擦成本」，不是「方便」

> 答辩主线只有一个词：**摩擦成本**。别讲"方便"，讲"摩擦降到多低 + 谁在为此流失"。

- **记账 App 的 30 日留存极低**，根因不是"不想记账"，而是**单次动作摩擦太高**：打开 App → 记账页 → 输金额 → 选分类 → 选账户 → 确认，≥6 步；忘了记还要补记，摩擦更高。
- 用户的真实形态是：**尝试过多次，每次都卸载**——不是不需要记账，是坚持不下来。
- 本产品把摩擦压到**一句话**：发「午餐28元」→ NLU 解析 → 落账 → 回复"已记录：三餐 ¥28.00"。不需要打开任何东西。
- 但"降低单次摩擦"只解决了一半——坚持还得靠**主动推送形成习惯回路**：
  - **月底自动发消费总结**（不用用户来问）
  - **异常提醒**（某天支出异常、预算快超时主动预警）
  - **快记提醒**（按时段行为数据，提醒"你平时这个点会记一笔"）
- 一句话总结：**别的工具让你"记得记"，这个机器人让你"不用记也会被记着"。**

---

## 技术底牌：复用自有技术，非从零（答辩关键论据）

> 这不是"又一个聊天机器人"——NLU、洞察、网关全是本团队在 RinklNote 里**已经写好并线上运行**的自有实现，可直接迁移为独立产品的内核。

| 能力 | 复用来源（RinklNote 已实现） | 作用 |
|---|---|---|
| 消息网关 | `QQBotWebSocketClient`（WS 长连接 + 心跳 + 指数退避重连） | 收/发 QQ 消息，无需公网 webhook |
| 意图路由 | `QQMessageProcessor` + `QQIntentRouter`（纯自然语言，无指令前缀） | 记账/查账/删除/总结/异常/建议自动分流 |
| NLU 解析 | `NLUService`（`RuleBasedParser` + `LLMParser` 双通道） | 「午餐28元」→ 金额+分类；断网也能本地规则兜底 |
| 消费洞察 | `InsightService`（monthly / anomaly / suggest / naturalQuery） | 月结、异常检测、按时段推荐 |
| 纠错能力 | `QQIntentRouter.deleteIntent` | 「删除午餐」「删掉刚才那笔」，试错零成本 |
| 消息去重 | `WebhookEventTable` 幂等 | 断线重发不重复落账 |

**迁移方式（Week 8）**：把上述模块组装成独立服务 = 独立 `BotService` + 独立用户体系（QQ 直接开通账号，不依赖 App）+ 极简 Web 看账页。现有代码 80% 直接搬运复用，剩下的是把"绑定 App 账号"改成"QQ 即账号"。

## AI 脱敏与隐私（答辩必问点 + 写进 PRD 的设计约束）

> 记账数据是最私密的个人数据，而 NLU/总结/异常都经过 LLM。**"AI 到底见到什么"是答辩最可能被追问的点**，也是独立产品最该主动设计的信任资产。

### 现状：RinklNote 已有的脱敏基线（代码已核实）

| 能力 | LLM 拿到什么 | 脱敏程度 |
|---|---|---|
| 记账解析「午餐28元」 | 仅这一句文本 + 分类表 | ✅ 最少必要 |
| 月度总结 | 仅聚合：月总额 + TOP5 分类 | ✅ 无明细、无备注 |
| 异常检测 | 纯本地计算，不调 LLM | ✅ 零外传 |
| 自然问账 | 问句 + **最近 10 笔明细（含备注）** | ⚠️ **泄露点** |

服务自建（阿里云），数据只在本机 + 模型 API 一跳；LLM 请求中**不含任何用户标识**（无 QQ openid/手机号）。当前唯一缺口：`naturalQuery` 把最近 10 笔的备注一起送进了 LLM（`InsightService.kt`）。

### 独立产品要补齐的（写进 PRD）

1. **聚合化**：洞察类一律送聚合（分类/月总额），不送明细。
2. **备注脱敏**：送 LLM 前剥离备注（备注是个人信息的重灾区），问账只送「分类 + 金额 + 日期」聚合。
3. **身份匿名化**：LLM 调用统一用匿名 user hash，不传真实身份。
4. **不落盘**：原始聊天文本过即弃，仅存记账必要字段（金额/分类/时间）；LLM 输入输出不持久化。
5. **本地优先**：规则引擎先判，简单记账**不触发任何 LLM 调用**——多数消息根本不出服务器。
6. **可关闭**：隐私敏感用户可关 AI（只用规则引擎），不牺牲核心记账功能。

### 答辩口径（一句话版）

> 我们对 AI 脱敏的原则：**最小化（只送该送的）、聚合化（不送明细）、匿名化（不送身份）、不落盘（不留痕）、可关闭（用户可选）**。你的账单，AI 只见它该见的。

## 答辩弹药（challenge 预演）

### Q1. "这不就是 RinklNote 的 QQ 机器人功能吗？怎么算独立产品？"

- **不是功能，是产品形态的不同**：RinklNote 的机器人是 App 的附属入口——必须先下载 App、注册、绑定 QQ，机器人只是 App 的一个遥控器。
- 本产品**无 App**：用户加个好友，在 QQ 里直接开通账号，从记账到查账到月结全在聊天里完成，整个生命周期不碰 App。
- 目标人群也变了：前者服务"已有记账 App 的人"，后者服务"**不想装 App、在 QQ 里顺手记**的人"。
- 技术是自有的、迁移的，不是抄袭的——复用自家沉淀，是团队优势不是减分项。

### Q2. "聊天记账/语音记账做烂了（微信记账本、鲨鱼语音、支付宝）？"

- 它们都是**App 内的一次性输入**：识别一句语音/文本，帮你填好一张表单，你仍要打开 App、面对 App。
- 本产品是 **IM 原生对话闭环**：记账、查账、删除、月结、异常提醒**全部在聊天里完成**，并且**主动推送**——你不打开任何东西，月底总结自己会来。
- 类比：Siri 是"一次性指令"，对话框里的智能助理是"持续关系"。前者是工具，后者是习惯。

### Q3. "单一平台依赖 QQ，风险太大？"

- QQ 官方 Bot 是**正规开放平台**（有正式接入规范、开发者文档、审核机制），比微信个人号接口友好得多，合规性不是问题。
- **v1 单平台切入是对的**：目标人群（学生/年轻上班族）在 QQ 密度高；MVP 就该单平台验证，不撒胡椒面。
- **内核可迁移**：NLU + 洞察 + 路由都是自有层，未来接企业微信/飞书/钉钉只是换网关，不换产品。
- 单平台验证 PMF 之后再谈多平台——先证明"有人持续用"。

### Q4（预演追加）. "记账是伪需求/市场太小？"

- 记账不是需求不足，是**留存差**。用户反复尝试、反复卸载，说明意愿真实存在，死在了摩擦上。
- 我们切入的是"**坚持**"这个被所有人忽视的环节：不跟你拼功能，拼的是"你卸不掉"。
- 市场叙事：高频小额、天然复购（每月都记）、数据在你自己手里（隐私资产）。

### Q5（预演追加）. "AI 含量在哪？会不会被说成套壳？"

- **NLU 是自有规则 + LLM 双通道**：规则引擎保证「打车20元」秒级离线可解析，LLM 兜底复杂表达；不是接一个 API 就完事。
- **总结/异常是 LLM 生成 + 行为数据驱动**：月结文案、异常检测、快记提醒，都是拿用户自己的账单数据喂出来的。
- 语音转文字、自然语言查账、主动洞察——三块都是真 AI，且都已在生产环境验证。

### Q6（预演追加）. "怎么变现？用户凭什么信任你？"

- 变现：基础记账免费，增值收费（高级洞察 / 多账户 / 家庭成员 AA）。
- 信任 = **脱敏是主动设计，不是事后补救**：AI 只见聚合不见明细（§AI 脱敏）、原始文本不落盘、可导出可删除、可一键关闭 AI、QQ 绑定走官方授权流程。账单数据用途公开说明。

## 立项自检（Week 6 上会前逐条确认）

- [ ] **人群有行为证据**：我在答辩里能说出"我问过 N 个朋友，都装过记账 App 又卸载"——**建议实际去问 5-10 个人，把原话记下来**，这是最有说服力的论据。
- [ ] **痛点够具体**：摩擦 → 坚持，一句话讲清（✓ 本文件 §叙事）。
- [ ] **一个页面能讲清**：这张图 = 一句话 + 一个聊天记录截图（「午餐28元」→「已记录」+ 月底月结卡片）。答辩 PPT 第一屏就放它。
- [ ] **差异化锋利**：IM 原生对话闭环 + 主动推送 ≠ App 内一次性输入。

## 边界：做什么 / 不做什么（v1）

**做**：私聊记账流（一句话落账 + 回复确认）、问账（今日/本月/分类/预算/最近/删除）、月底自动月结卡片、异常提醒、快记提醒、极简 Web 看账页。

**不做（v1）**：群共享记账、AA 分摊、多平台、家庭账号。群共享/AA 是 v2 锋利 wedge——答辩可主动提"我们想清楚 v1 只做个人坚持"，展示克制。
