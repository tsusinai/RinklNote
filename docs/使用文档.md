# RinklNote 使用文档

RinklNote 是一个 Android + Web 双端个人记账应用，支持手动记账、自然语言输入、QQ 机器人快捷记账。

## 快速开始

### Android App
1. 安装 APK 后打开 App（无需注册即可使用本地记账）
2. 如需数据同步和 QQ 机器人，在"设置"页登录/注册账号
3. 登录后可在"资产"页点击"同步"按钮同步多端数据

### Web 端
1. 浏览器打开 `http://118.31.184.221/`
2. 在"设置"页登录或注册
3. 登录后可记账、查看账单、管理模板和关键词

## 记账方式

### 方式一：手动选择（数字键盘）
1. 点击右下角 FAB 打开记账抽屉
2. 切换支出/收入
3. 选择分类（长按可展开子分类）
4. 选择账户（微信/支付宝/默认）
5. 点击金额区域 → 弹出数字键盘 → 输入金额
6. 键盘确认 → 绿勾确认 → 记账完成

### 方式二：自然语言输入（NLP）
在记账抽屉顶部的输入框直接输入文字：

| 输入 | 识别结果 |
|------|---------|
| 午餐25元 | 分类=三餐, 金额=25 |
| 打车15块 | 分类=交通, 金额=15 |
| 买书50元 | 分类=学习, 金额=50 |
| 工资5000 | 分类=工资, 金额=5000 |

点击"识别"按钮 → 自动填入分类和金额 → 确认即可。

离线时也能识别数字金额，分类需联网。

### 方式三：模板一键记账
将常用消费保存为模板，点一下直接记账：

- **创建模板**：选择分类+金额 → 点击模板栏的 "+" 按钮
- **使用模板**：点击模板按钮直接记账（跳过确认）
- **管理模板**：长按模板可编辑/删除；Web 设置页也可管理

### 方式四：QQ 机器人
向绑定的 QQ 机器人发送消息即可记账（见 [QQ 机器人](#qq-机器人)）

### 方式五：智能推荐
打开记账抽屉时，如果某个时段你习惯记某类账单（如每天早上记早餐 ¥15），会弹出推荐气泡。点击即可一键记账。可在 Web 设置页调整推荐参数。

## 账单管理

### 查看账单
- **App**: 底部导航 → "记账"tab → 按月分组查看
- **Web**: 顶部导航 → "账单" → 搜索/筛选/导出 CSV

### 编辑账单
- Web 端点击账单的分类名称 → 弹出下拉框 → 选择新分类
- App 端暂不支持编辑（规划中）

### 删除账单
- Web 端：目前通过 API 支持（UI 规划中）
- 删除为软删除，服务端保留记录

## 图表分析

Web 端提供三种图表：
- **饼图**：支出分类占比
- **柱状图**：每日支出趋势
- **折线图**：月度收支对比

支持本周/本月/本年切换。

## QQ 机器人

### 接入步骤
1. 在 [QQ 开放平台](https://q.qq.com) 创建机器人，获取 AppID 和 ClientSecret
2. 登录 Web 设置页 → "QQ 机器人"板块 → 填入凭证 → 保存
3. 在 QQ 开放平台配置 Webhook URL: `http://118.31.184.221/api/qq/bot/webhook`
4. 向机器人发送消息，获取 6 位绑定码
5. 在 Web 设置页输入绑定码完成绑定

### 使用
向机器人发送消息即可记账，格式同 NLP 输入：
- "午餐25元" → 记录三餐 ¥25
- "打车15" → 记录交通 ¥15

机器人回复："已记录: 三餐 ¥25.00"

## Web 端设置

登录后可配置：
- **QQ 机器人**：配置凭证、查看状态、绑定/解绑 QQ
- **记账模板**：添加/删除模板
- **关键词管理**：自定义关键词 → 分类映射
- **智能推荐**：启用/关闭、调整回溯天数、最少出现次数、显示时长

## 同步说明

- **本地优先**：Android App 所有数据先存本地，后台同步到服务器
- **多端数据合并**：Web 和 Android 的数据会双向同步
- **冲突处理**：最后修改的版本优先（Last-Writer-Wins）
- **手动同步**：App "资产"页 → 点击同步按钮
- **自动同步**：记账后自动推送，打开资产页自动拉取
