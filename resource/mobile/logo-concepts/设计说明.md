# 记一笔移动端标识提案

目标：去除二次元形象，以简洁、平静、易识别的几何标识适配移动端；保留现有蓝色 #7EC1FC，平面呈现，不使用阴影、渐变和文字字体。

探索方向：开环与新增一笔、R 字母连续笔画、收支页签、双账页、记录节点、折角账本、平衡刻度、时间环、留白票据、圆点印章。排除泛用的上升箭头、盾牌、钱袋以及复杂货币符号。

最终展示三种不同标识类型：

- A 开环记一笔：圆环打开一角，新增符号与两条记录线建立记账语义，延续旧记账入口的开环结构。推荐，识别语义最直接；小尺寸需保持符号与圆环间的空隙。
- B 一笔 R：RinklNote 首字母，圆角字腔与斜向收笔，识别最精练；风险是记账语义较弱。
- C 收支页签：两块交错页签形成正负空间，表达收入与支出的平衡；风险是抽象程度较高。

构造采用 256 网格。v1 保存初稿；v2 改善开环间距、R 收笔重心和页签中间留白。先检查单色及 16/32/64px，再选择方向。方案文件不依赖字体或外部图片。

选定后应用：Android 自适应启动图标、圆形及单色图标、应用内品牌标识与默认头像；最终形态需在圆形、圆角矩形及小尺寸下验证。
