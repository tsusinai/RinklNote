# RinklNote Web 控制台

Vite + Vue 3 + TypeScript + Pinia + Vue Router + ECharts。

```bash
npm install
npm run dev        # http://localhost:5173，/api 代理到 Ktor :8080
npm run typecheck  # vue-tsc --noEmit
npm test           # vitest run
npm run build      # vue-tsc --noEmit && vite build → web/dist
```
